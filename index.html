Matching logic applied

Priority ladder (first match wins, one AWB per orphan)

  1. Same site · FLOOR pendency · exact (orphan ageing < salvaging ageing preferred)
  2. Same site · LOSS pendency · exact
  3. Cross-site · FLOOR · near-exact, salvaging ageing > 20 days
  4. Cross-site · LOSS · near-exact, salvaging ageing > 20 days
  5. Combo Base · same site · exact (each combo item matched to a different orphan)
  6. Combo Base · cross-site · near-exact, ageing > 20 days
  7. Same site · FLOOR · similar product (70–84%)
  8. Same site · LOSS · similar product (70–84%)
  9. Combo Base · same site · similar product

Hard checks on every match

  • Brand + product type + key attributes must agree; 70% is the floor, 85%+ is Exact, cross-site needs 90%+.
  • Category must agree with what the salvaging description is (Footwear brand ≠ jeans).
  • Volume / weight / pack count must match when both sides state it (200 ml ≠ 400 ml).
  • Accessory never matches a primary product (cover, case, guard, cable ≠ phone).
  • Brand only → Brand column, else Entered Brand; description only → description vs description.
  • Ties broken by ageing fit, then picked month Sep › Aug › Jul › Jun › May › Apr › Mar.
  • No brand and no description, or packaging-only text (plastic bag, box, Shadowfax), is excluded with a reason.

FLOOR vs LOSS

  • Uses a PENDENCY TYPE column if present; otherwise Loss Bucket Sub Tagging containing "Floor" = FLOOR, everything else = LOSS.
